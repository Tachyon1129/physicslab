# PhysicsLab

A guided physics learning app, from first steps to research level: simulators, step-by-step derivations, a hint-based tutor, quizzes and XP progress.

It installs as an app on iPhone (Safari → Share → Add to Home Screen) and on PC (Chrome or Edge → Install icon in the address bar), and it works offline after the first launch.

Live at https://tachyon1129.github.io/physicslab/ once GitHub Pages is switched on (Settings → Pages → Deploy from a branch → main → / (root)).
